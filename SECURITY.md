# Security Policy

## Reporting a vulnerability

The SweetRPG platform is an open source project run as a public service. The project
maintainers request responsible disclosure of security vulnerabilities.

Please do not report security issues through the public GitHub issue tracker. Instead, report
them to one of the project maintainers directly via email:

| Contact | E-mail address |
|---|---|
| Paul | [paul@sweetrpg.com](mailto:paul@sweetrpg.com) |

Please include a description of the issue, the steps you took to create the issue, affected
versions, and, if known, mitigations for the issue.
